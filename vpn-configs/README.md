# Public WireGuard configuration templates

These are sanitized copies of the supplied WireGuard configurations.

**PrivateKey values were intentionally removed.** Real WireGuard private keys must not be committed to this public repository.

To use a template, replace `YOUR_PRIVATE_KEY_BASE64` with the private key belonging to the same client configuration. For actual use in the Android app, import the original private ZIP locally; the app stores imported credentials encrypted on the device.
