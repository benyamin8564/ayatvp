# WireGuard Gateway

این پروژه از کتابخانه رسمی WireGuard Android برای اجرای WireGuard استفاده می‌کند؛ پروتکل سفارشی یا obfuscation اضافه نشده است.

## سمت سرور
برای هر دستگاه یک peer بسازید و این موارد را در `servers.json` قرار دهید:
- `host` و `port`: endpoint سرور WireGuard
- `publicKey`: کلید عمومی سرور
- `address`: آدرس اختصاصی کلاینت
- `allowedIps`: معمولاً `0.0.0.0/0, ::/0`
- `healthUrl`: یک endpoint HTTPS سبک برای سنجش در دسترس بودن/تاخیر سرور

کلید خصوصی کلاینت توسط اپ تولید می‌شود و در Android Keystore رمزنگاری می‌شود؛ کلید خصوصی را در مخزن GitHub قرار ندهید.

## چند سرور و انتخاب خودکار
اپ latency را از طریق `healthUrl`های HTTPS اندازه می‌گیرد و سالم‌ترین/کم‌تاخیرترین سرور را انتخاب می‌کند. اگر health endpoint تعریف نشده باشد، اولین سرور fallback است.

## به‌روزرسانی امن کانفیگ
به‌روزرسانی از URLهای `https://` پذیرفته می‌شود و امکان pin کردن SHA-256 محتوای فایل وجود دارد. برای محیط تولید بهتر است علاوه بر HTTPS از امضای دیجیتال فایل کانفیگ با یک کلید عمومی ثابت در خود اپ استفاده شود؛ هرگز کلید خصوصی امضا را در APK یا repository قرار ندهید.
